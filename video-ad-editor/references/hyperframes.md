# HyperFrames — محرّك مساعد للمشاهد الجاهزة والرندر من الجوال

إطار مفتوح من HeyGen (رخصة Apache 2.0، بلا رسوم رندر) يحوّل صفحة HTML فيها حركات GSAP إلى MP4 فريم بفريم، ونفس المدخل يعطي نفس الفيديو كل مرة.
**ما يحل محل المحرّك الخفيف.** نستخدمه في ثلاث حالات بس.

## متى نستخدمه

| الحالة | ليش |
| --- | --- |
| مشهد يحتاج رسم بيانات متحرك، أو خريطة، أو انتقال شيدر، أو نص حركي معقّد | فيه مكتبة قرابة 450 بلوك جاهز. نسحب البلوك ونلبسه هوية بو ناصر بدل ما نبنيه من الصفر |
| ريل تحليلي بلا تصوير وبو ناصر بالجوال وما عنده جهاز | موصل HyperFrames by HeyGen يبني ويرندر بالسحابة (`compose` ثم `render_video`) ويرجع رابط مشروع |
| مشهد واحد مكتوب HTML ونبيه MP4 بدقة ثابتة | `npx hyperframes render` بلا بناء ولا React |

لتسجيلات الكاميرا والكابشن بتوقيت الكلمة يبقى الشغل على المحرّك الخفيف كالعادة.

## على جهازه (Claude Code)

```bash
npx skills add heygen-com/hyperframes --skill hyperframes      # مرة وحدة، بإذنه
npx hyperframes init <work>/hf && cd <work>/hf
npx hyperframes add data-chart        # أمثلة بلوكات: flash-through-white, kinetic-type, map
npx hyperframes preview               # معاينة حية بالمتصفح
npx hyperframes render                # MP4
```
يحتاج Node 22 فما فوق و FFmpeg (موجودة أصلاً مع المحرّك).
الأبعاد للريل `data-width="1080" data-height="1920"`.
المقطع الناتج يدخل التايملاين كأي لقطة عادية.

## من الجوال (الموصل)

- `compose` بوصف المشهد بالعربي، وبعده `get_project_status` حتى يخلص، ثم `render_video`.
- النمط `signal` للإحاطات التحليلية، والمطلوب ألوان هوية بو ناصر لا ألوان النمط.
- النتيجة مشروع على حسابه بـ HeyGen، يفتحه ويعدّل بنفسه.

## قواعد إلزامية

- الألوان والخط من `theme.json` لا غير. البلوك الجاهز يُعاد تلوينه قبل الرندر.
- **اختبار العربي قبل أي اعتماد:** اتجاه النص من اليمين `dir="rtl"`، الحروف متصلة بلا تقطّع، والأرقام غربية. اعرض لقطة ثابتة من الفريم قبل الرندر الكامل.
- ولا رقم أو اسم على الشاشة من برّا `facts.md`.
- بلا مصطلحات معه. ما تقول «HyperFrames» ولا «بلوك». قل «مشهد جاهز ألبسه ألوانك».
- ما ينشر ولا يجدول. التسليم ملف أو رابط مشروع.
