### أدوات مراجعة الريل: claude-video وffmpeg-skill (5 نوفمبر 2026)

أداتان راجعهما بو ناصر وصارتا طبقة مراجعة إضافية قبل التسليم. **لا تستبدلان** `reel-review-loop` ولا `timing-qa.md` ولا `07_contact_sheet.sh` ولا `08_safe_check.js`، تضيفان فوقها. تعملان بكلود كود فقط، لا بالدردشة ولا كوورك. لا تقترحهما من نفسك، فقط عند طلبه مراجعة ريل أو تحليل ريل منافس.

## 1) claude-video (أمر watch)
يخلي Claude يشوف الفيديو: رابط أو ملف يتحوّل لإطارات بتوقيتها ونص منطوق. المستودع bradautomates/claude-video ورخصته MIT.

التركيب بكلود كود
```
/plugin marketplace add bradautomates/claude-video
/plugin install watch@claude-video
```
المتطلبات: بايثون 3.10 فأعلى وffmpeg وyt-dlp. على ويندوز: `winget install --id Gyan.FFmpeg --exact` و`winget install --id yt-dlp.yt-dlp --exact`. يُنادى بـ`/watch:watch` لو مثبّت كبلقن، أو `/watch` لو مثبّت كمهارة مستقلة (هذا اللي على جهاز بو ناصر عبر `bunasser77/scripts/studio_setup.ps1`، والتفاصيل بـ`bunasser77/references/studio-tools.md`).

**متى:**
- مراجعة النسخة النهائية قبل التسليم، وطلب ملاحظات بالثواني على الهوك والإيقاع والكابشن.
- تحليل ريل منافس أو مرجعي وتفكيك بنيته (هوك، تحولات، خاتمة). للنسخ الفعلي للأسلوب اقرأ مهارة `reel-style-fingerprint`.
- الأفضل ريل أقصر من 10 دقائق، أو مقطع محدد: `--start 0:00 --end 0:15`.

**قواعد بالعربي:**
- اضبط لغة النطق `WATCH_WHISPERX_LANGUAGE=ar` وإلا قد يخطئ النموذج الصغير بتمييز اللغة.
- لدقة أعلى `WATCH_WHISPERX_MODEL=large-v3` (تنزيل نحو 2.9 جيجا ورام نحو 6 جيجا).
- لقراءة نص مكتوب على الشاشة ارفع الدقة `--resolution 1024`.
- نص الكابشن المحروق بالفيديو يُقرأ من الإطارات لا من النطق، فتأكد منه بعينك على الورقة.

**الخصوصية ⛔:**
- المحرك `local` يشتغل على الجهاز ولا يرفع شي.
- المحرك Gemini يرفع الفيديو لقوقل ويحذفه بعد الجواب. لا تستخدمه لمواد غير منشورة إلا بإذن بو ناصر.
- مفاتيح API تُوضع بـ`~/.config/watch/.env` ولا تُلصق بالمحادثة.

## 2) ffmpeg-skill (kajisho5)
محرك فيديو محلي بـ42 أداة، بلا سحابة وبلا مفاتيح، رخصته MIT. يُستخدم هنا طبقة فحص وتسليم، لا بديلاً عن المحرك.
```
npx ffmpeg-skill
npx ffmpeg-skill doctor
```
الأدوات بـ`~/.claude/skills/ffmpeg-skill/scripts` (على ويندوز `python` بدل `python3`).

| الحاجة | الأمر |
|---|---|
| فحص مواصفات الريلز مع علاج كل خلل | `python3 check.py ريل.mp4 --platform reels` |
| ورقة لقطات تظلّل مناطق واجهة إنستغرام (لفحص الكابشن والعناوين) | `python3 look.py ريل.mp4 --safe reels` |
| ضبط الصوت 14 LUFS وذروة 1- dBTP | `python3 loudness.py ريل.mp4 -I -14 --tp -1` |
| فحص محتوى (إطار أسود، إطار متجمد، صمت) | `python3 check.py ريل.mp4 --content` |
| هل الخط العربي متوفر قبل حرق الكابشن | `npx ffmpeg-skill doctor --json` (حقل fonts.scripts عند ar) |

**⚠️ العربي:** كاسر الأسطر `--wrap phrase` مصمم للاتينية والآسيوية، فلا تعتمد عليه بكابشن عربي أو مختلط. كابشن بو ناصر يبقى من المحرك وقواعد `reel-caption-bidi-guard`. من ffmpeg-skill خذ الفحص والقياس فقط.

> ملاحظة صدق: قراءة هذا المرجع للتوثيق شملت النصف الأول من صفحة ffmpeg-skill (الأدوات والتركيب). جرّب كل أمر على ريل تجريبي قبل الاعتماد عليه.

## الترتيب المقترح قبل التسليم
1. `/watch` على النسخة النهائية لملاحظات الهوك والإيقاع.
2. `check.py` ثم `look.py --safe` ثم قياس الصوت.
3. تُعدَّل الملاحظات وحدة وحدة (بو ناصر يقرر)، وتُعاد الدورة مرة واحدة فقط.
