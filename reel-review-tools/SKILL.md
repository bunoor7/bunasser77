# أدوات مراجعة الريل

تكمّل reel-review-loop وreel-delivery-checks ولا تستبدلهما. تعمل الأدوات داخل Claude Code فقط، ولا تعمل في الدردشة العادية ولا كوورك.

## claude-video (أمر watch)
يجعل Claude يرى الفيديو من رابط أو ملف، بإطارات مؤقتة ونص منطوق. المستودع bradautomates/claude-video ورخصته MIT.

التركيب داخل Claude Code
```
/plugin marketplace add bradautomates/claude-video
/plugin install watch@claude-video
```
المتطلبات بايثون 3.10 فأعلى وffmpeg وyt-dlp. على ويندوز يُركّب ffmpeg وyt-dlp بـ winget.

متى يُستخدم
- مراجعة ريل جاهز قبل النشر، وطلب ملاحظات بالثواني على الهوك والإيقاع والكابشن.
- تحليل ريل منافس أو مرجعي وتفكيك بنيته (هوك، تحولات، خاتمة).
- قاعدة الاستخدام، ريل أقصر من 10 دقائق أو مقطع محدد بـ --start و--end.

قواعد خاصة بالعربي
- اضبط لغة النطق على العربية (WATCH_WHISPERX_LANGUAGE=ar) وإلا قد يُخطئ النموذج الصغير في تمييز اللغة.
- للدقة الأعلى جرّب WATCH_WHISPERX_MODEL=large-v3 (تنزيل نحو 2.9 جيجا ورام نحو 6 جيجا).
- لقراءة نص مكتوب على الشاشة ارفع الدقة بـ --resolution 1024.

الخصوصية
- محرك local يعمل على الجهاز ولا يرفع شيئًا.
- محرك Gemini يرفع الفيديو إلى Google ويحذفه بعد الإجابة. لا يُستخدم مع مواد غير منشورة أو حساسة إلا بإذن بو ناصر.
- لا تُلصق مفاتيح API في المحادثة، تُوضع في ~/.config/watch/.env.

## ffmpeg-skill (kajisho5)
محرك فيديو محلي بـ 42 أداة بلا سحابة ولا مفاتيح. رخصة MIT.
```
npx ffmpeg-skill
npx ffmpeg-skill doctor
```
يُستخدم هنا كطبقة فحص وتسليم، لا بديلًا عن video-ad-editor.
- check.py --platform reels فحص مواصفات التسليم مع علاج كل خلل.
- look.py --safe reels ورقة لقطات مع تظليل مناطق واجهة إنستغرام لفحص الكابشن والعناوين.
- loudness.py بهدف -14 LUFS و-1 dBTP.
- render.py --template reels لتصدير بقالب جاهز بمناطق آمنة.
- doctor يعرض هل الخط العربي (ar) متوفر قبل حرق الكابشن.

تنبيه عربي. كاسر الأسطر phrase wrap مصمم أساسًا للاتينية والآسيوية، فلا يُعتمد عليه في الكابشن العربي المختلط. يبقى reel-caption-bidi-guard المرجع، وتُفحص كل لقطة كابشن بـ look.py.

## الترتيب المقترح قبل التسليم
1. watch على النسخة النهائية لملاحظات الهوك والإيقاع.
2. check.py ثم look.py --safe ثم قياس الصوت.
3. تُعدَّل الملاحظات، وتُعاد الدورة مرة واحدة فقط.
