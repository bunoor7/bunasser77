# الفهرس الذكي

خريطة توصل إلى ما في البلقن. لا يغني عن المهارات: يدلّك على المهارة أو الملف، ثم تفتحه وتطبّق قواعده. وقواعد بو ناصر في `bunasser77/SKILL.md` فوق كل شيء.

## كيف تستعمله
1. **حدّد سؤال اللحظة:** حركة كلمة؟ انتقال؟ خط؟ ستايل؟ صوت؟
2. **لحركة مرتبطة بكلمة في السكربت** افتح `references/motion-vocabulary.md`: ابحث عن عائلة معنى الكلمة («طويل» في «الطول والامتداد»)، واختر خيارًا لم يُستعمل قريبًا في الريل.
3. **لأي شيء آخر** افتح `references/catalog.md`، واذهب إلى الفئة، ثم افتح المصدر المذكور في عمود «أين».
4. **النسخة الآلية** في `index.json` (الكتالوج، وجدول المعاني، والقواعد)، لمن يقرأ بالكود أو للوكيل.
5. **لم تجد ما يناسب؟** ابحث في بلوكات HyperFrames: `npx hyperframes catalog --query "<الحركة بالإنجليزي>"`. فإن لم تجد، فلا تبنِ باليد قبل أن تقول ذلك لبو ناصر.

## الفئات
| الفئة | السؤال |
| --- | --- |
| حركة النص والكلمات | كيف تدخل هذه الكلمة وتتحرك؟ |
| مؤثرات بصرية للحظة | صدمة، كشف، أرقام، خاتمة؟ |
| انتقالات | من مشهد إلى التالي؟ |
| حركة الكاميرا والإحساس | كيف تتحرك الكاميرا وبأي تسهيل؟ |
| خطوط | أي خط؟ |
| ستايلات الريل كله | أي شكل للريل؟ |
| قوالب جاهزة | هل يوجد قالب يغني عن البناء؟ |
| السرد والهوك | كيف نبني الحكاية والبداية؟ |
| الصوت | أي صوت ومن أين؟ |
| الفحص والتسليم | هل الريل جاهز؟ |

## الوكيل
لتخطيط حركات مشهد أو ريل كامل كلمة بكلمة، استدعِ الوكيل `motion-director`. يقرأ هذا الفهرس، ويختار وينوّع، ويعيد خطة بالتوقيت. وإن لم يجد شيئًا مناسبًا، يعود إليك بما ينقص.

## التحديث
البيانات كلها في `build.py`. عند إضافة مهارة أو أداة إلى البلقن، أضف سطرها هناك، ثم شغّل `python -I reel-library-index/build.py` من جذر البلقن، فيُعاد توليد `index.json` و`references/catalog.md` و`references/motion-vocabulary.md`. لا تعدّل الملفات المولّدة باليد.
