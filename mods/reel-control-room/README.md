# reel-control-room

لوحة جانبية في Claude Code تعرض مراحل الريل الحالي: السكربت، المونتاج، الصوت، الكفر، التسليم.
تقرأ الحالة من `status.json` داخل مجلد المشروع في `C:\Edit with AI\Projects\<اسم الريل>`،
وتتحدّث كل ثلاث ثوانٍ. الريل الحالي هو المشروع الذي عُدّل ملف `status.json` فيه آخر مرة.

كل شيء محلي: الـMod يقرأ الملفات فقط، ولا يستدعي أي موديل، ولا يتصل بالشبكة، ولا يشغّل أي برنامج.

## شكل status.json

```json
{
  "reel": "ريل الكهرباء",
  "stages": {
    "script": "جاهز",
    "edit": "قيد العمل",
    "sound": "بانتظار قراري",
    "cover": "لم يبدأ",
    "delivery": { "status": "لم يبدأ", "note": "بعد اعتماد الكفر" }
  }
}
```

- الحالات: `لم يبدأ`، `قيد العمل`، `بانتظار قراري`، `جاهز` (أو `not_started`، `in_progress`، `needs_decision`، `done`).
- المراحل: `script`، `edit`، `sound`، `cover`، `delivery`، وتُقبل أسماؤها العربية أيضًا (السكربت، المونتاج، الصوت، الكفر، التسليم).
- المرحلة غير المذكورة تُعرض «لم يبدأ». والحالة غير المفهومة تُعرض بتحذير أحمر.

## ما تعرضه اللوحة

- **لا يوجد مشروع**: إذا لم يوجد مجلد `Projects` أو كان فارغًا، مع مثال للملف.
- **لا يوجد status.json** في أحدث مشروع.
- **status.json فارغ** أو **تالف**: مع سبب الخطأ، وتتحدّث اللوحة وحدها بعد التصحيح.
- **المراحل** بعلامة ولون لكل حالة.

## التنبيه ووضع الهدوء

- يظهر تنبيه منبثق داخل الواجهة مرة واحدة عند اكتمال مرحلة أو احتياجها قرارك، ويبقى سطر «تنبيه» في اللوحة حتى تضغط «تم».
- كل تنبيه يُحفظ، فلا يتكرر بعد إعادة التحميل أو في جلسة جديدة. وإذا تغيّرت الحالة ثم عادت يتكرر التنبيه.
- أول مرة يُرى فيها مشروع، لا تنبيه عن المراحل الجاهزة أصلًا. أما «بانتظار قراري» فيُنبَّه عنه.
- **وضع الهدوء**: زر في اللوحة أو الأمر `/reel-room-quiet`. يوقف التنبيه المنبثق، ويبقى السطر في اللوحة فقط. يبقى الوضع محفوظًا بين الجلسات.

## الأوامر

- `/reel-room`: يفتح اللوحة ويحدّثها.
- `/reel-room-quiet`: يشغّل وضع الهدوء أو يوقفه.

## التثبيت

من مستودع bunasser77:

```
/plugin install reel-control-room@bunasser77
```

## التعطيل

```
/plugin disable reel-control-room@bunasser77
```

وللإعادة: `/plugin enable reel-control-room@bunasser77`. وللإزالة نهائيًا: `/plugin uninstall reel-control-room@bunasser77`.
