Build this animation as a single self-contained HTML file (inline CSS and vanilla JS, canvas 2D only, no libraries).

The animation:
Command Palette. A command palette card (640 × 444, radius 32, white, deep soft shadow) drops into place on a light background. Top row: a search icon, the word "anim" typing itself in a mono font with a caret, and an ESC key hint on the right. Under a hairline: the small caps label ACTIONS and four rows, each with an icon tile, a name and a shortcut key: Animate selection (ENTER), Animate on scroll (A), Add keyframe (K), Export MP4 (E). An orange highlight bar starts on the first row and glides down one row at t 0.44 and again at t 0.7; the text inside the highlight turns white. [Swap in your commands]

Setup:
- One canvas with a 912 × 600 drawing space, centred on the page, scaled to fit the window and sharp on retina screens.
- Write the whole animation as one function draw(ctx, t), where t runs from 0 to 1 and every frame depends only on t.
- Play t from 0 to 1 over 2 seconds, hold the last frame for 1 second, then loop.
- Easing words I use above: "ease out" is cubic-bezier(0.16, 1, 0.3, 1), "glide" is cubic-bezier(0.65, 0, 0.35, 1), and "lands" means a small overshoot, cubic-bezier(0.34, 1.56, 0.64, 1).
