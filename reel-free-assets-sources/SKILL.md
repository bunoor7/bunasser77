# مصادر أصول مجانية للريلات

يكمّل motion-video وhyperframes-blocks ولا يستبدلهما. اختر مصدرًا واحدًا فقط حسب حاجة المشهد، ولا تحمّل المشهد أدوات لا يحتاجها.

## المصادر
- **3dicons.co** أيقونات ثلاثية الأبعاد (PNG وملفات Blender) بترخيص CC0 بلا نسبة. تناسب كارتات الموشن والغلاف والمشاهد التعريفية. ملاحظة المحرر المدفوع (Pro) منفصل عن المجاني.
- **kitbitz.art** أكثر من ألفين رسمة باليد بصيغ SVG وPNG بترخيص CC0، ولها ربط MCP. تناسب ريلات الشرح ولقطات المساندة.
- **animejs.com** مكتبة حركة JavaScript خفيفة ومجانية. المفيد منها للريلات رسم الخطوط (createDrawable) وتحويل الأشكال (morphTo) ومسار الحركة (createMotionPath) والتتابع (stagger) والتايم لاين.
- **mapcn.dev** مكونات خرائط React على MapLibre وTailwind وshadcn، بتركيب npx shadcn@latest add @mapcn/map. تناسب ريلات الجغرافيا والمسارات. التزم بنسبة الخريطة إلى OpenStreetMap وCARTO في اللقطة أو الوصف.
- **liquidglass.dev** عناصر ويب بترخيص MIT تحاكي الزجاج السائل لأبل، وتصلح لواجهات وكارتات ديمو التطبيقات فقط. تعمل أفضل فوق صورة معروفة.

## لا تُستخدم للريلات إلا عند الطلب
- microkit.co وuiverse.io مكتبات واجهات وأزرار لبناء مواقع، وليست للفيديو.

## قواعد
1. اكتب مصدر كل أصل وترخيصه في ملف assets.md بجانب المشروع.
2. لا تخلط أكثر من أسلوب رسم في ريل واحد (ثلاثي الأبعاد مع مرسوم باليد) إلا بموافقة بو ناصر.
3. تأكد من صفحة الترخيص لكل أصل قبل النشر التجاري.
